### Rules this project will not trade

- Never invent scripture, a grade, a timing, a reciter, or a rule definition.
  Source it and cite it, or leave it honestly absent.
- Disagreement between authorities is **shown**, never resolved by us.
- No accounts, no server, no telemetry, no leaderboard, no gamified worship.
- Pagination stays opt-in and never interrupts a recitation.

## 4. Known, accepted, and still open

Recorded so "not done" is a decision with a reason rather than an omission.

| Item                                                                              | Why it is still open                                                                                                                                                                         |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No per-dhikr audio** (0 of 1,093 items)                                         | The single largest rival advantage. Needs a citable, licensed per-item audio source for ~1,100 items. `OPEN-ISSUES` 15.                                                                      |
| **Prayer methodology depth**                                                      | 7 methods against a rival's 23, and 2 Asr twilight conventions against 4. The _controls_ ship and are tested; the extra methods are a data project needing cited sources. `OPEN-ISSUES` 25c. |
| **Makharij + sifat course stages**                                                | Citable in principle (dossier §3–4) but needs the 17/16/14 makharij spread rendered rather than resolved. Not built.                                                                         |
| **200% type does not reach the mushaf's Arabic**                                  | The mushaf owns its typography, has its own slider and pinch, and Elder Mode now reaches it. Letting two scales fight over one line box would make neither predictable. Deliberate.          |
| **Mushaf: page-height sheet, 15-line grid, basmala voice, roundel on all papers** | Four real fidelity gaps from the object audit, each its own commit. Not started.                                                                                                             |
| **Install / distribution story (G3)**                                             | We cannot ship a native app inside a no-build PWA, but the install path can be made excellent. Not started.                                                                                  |
| **Per-city SEO pages (G4)**                                                       | Pure marketing surface, 300+ pages. **Owner decision**, not a build.                                                                                                                         |
| **iOS is second-class**                                                           | Wake-ups and storage eviction are platform limits, not bugs. `BLOCKED:device`.                                                                                                               |
| **202 tap targets under 44px, 38 under 24px**                                     | Measured at baseline. Elder Mode raises them all; the default does not.                                                                                                                      |
| **Row 13 — reciter metadata is uneven**                                           | Some voices lack bitrate ladders and availability data. Needs a census, then citable gaps rather than a guess.                                                                               |
| **Row 19 — tasbih cycle counters are unbounded**                                  | A long session grows the counter without a floor. Small, but it needs a decided limit, not an arbitrary one.                                                                                 |
| **Row 22 — iOS storage eviction and push limits are not in the README**           | Documentation debt about a real platform behaviour. Cheap, and nobody has written it down.                                                                                                   |
| **Row 26 — iOS cannot be relied on for prayer-time wake-ups**                     | A platform limit, not a bug. `BLOCKED:device`.                                                                                                                                               |
