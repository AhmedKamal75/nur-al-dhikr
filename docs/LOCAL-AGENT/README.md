# Local-Agent Layer

This directory is an execution layer for a local coding agent. It does not replace the project's authoritative `AGENTS.md`, `MEMORY.md`, architecture, testing or release documents.

Its job is to make the local agent:

- browser-evidence driven
- hostile toward visual slop
- bilingual/RTL aware
- feature-product oriented
- disciplined about offline releases
- capable of returning a reproducible evidence packet

Start with `START-HERE.md`.
