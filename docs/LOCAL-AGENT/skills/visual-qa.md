# Skill: Visual QA

## Purpose

Turn subjective complaints such as "this looks bad" into reproducible visual evidence.

## Procedure

1. launch the real app
2. choose an exact route/state
3. set exact viewport
4. set language
5. set theme
6. capture screenshot
7. inspect geometry
8. inspect hierarchy
9. inspect content density
10. inspect controls
11. inspect RTL/LTR
12. write the finding with severity

## Never

- compare different states
- use browser scaling to hide a defect
- rely only on source/CSS inspection
- call an unrendered layout fixed
