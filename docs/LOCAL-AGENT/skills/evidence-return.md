# Skill: Evidence Return

Your output is intended for another engineer, not only for yourself.

Return:

- exact commands
- exact results
- exact environment
- exact screenshot filenames
- exact known limitations
- exact changes
- exact remaining defects
- exact next experiments

Prefer:

> `focus-mode__reading__ar__dark__393x852.png` shows the primary counter is 18px too close to the bottom control rail.

over:

> Focus Mode spacing improved.

The first statement is actionable evidence. The second is a claim.
