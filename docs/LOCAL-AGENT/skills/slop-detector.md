# Skill: Slop Detector

Treat these patterns as suspicious until justified:

- every section inside a card
- every action as a pill
- every category with its own pastel color
- gradient for visual excitement with no semantic purpose
- glass on static content
- giant icons compensating for weak hierarchy
- three different radii on one screen
- detached CTA below its own card
- repeated labels saying the same thing
- dashboard statistics with no user decision attached
- decorative progress bars with no meaningful progress
- navigation duplicated in header + sidebar + bottom bar
- settings exposed as raw implementation toggles
- excessive uppercase micro-labels
- fixed-height containers around translated content
- inconsistent max-widths between sibling screens
- a feature rendered as a list of interchangeable cards when its task is sequential

When one instance appears, inspect siblings. The goal is class-level remediation.
