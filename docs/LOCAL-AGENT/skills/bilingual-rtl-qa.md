# Skill: Bilingual + RTL QA

Test every meaningful changed surface in both EN and AR.

Inspect:

- long Arabic labels
- mixed Arabic/English strings
- Arabic numerals and Latin digits
- slash-separated values
- punctuation
- icon placement
- chevrons/arrows
- progress indicators
- segmented controls
- drawers/sheets
- audio transport controls
- card ordering
- table/grid ordering

Use logical CSS properties unless an exemption is explicitly documented.

A screenshot that looks correct in EN does not certify AR.
