# Code of Conduct

## Our pledge

We pledge to keep this project a place where a person can seek help with worship
without being condescended to, manipulated, or misled.

## The standard

This is a religious application. That raises the bar on two axes:

**Towards people's faith.** Never fabricate a grade, a timing, an attribution,
or a translation. Never present an opinion as consensus. Never use
gamification mechanics — points, streaks-as-shame, confetti, leaderboards — to
drive engagement with worship. If the data is unknown, say it is unknown.

**Towards each other.** Assume good faith. Disagree about the work, never about
the person. Review the code, cite `file:line`, and prove claims by execution.
No harassment, no personal attacks, no religious sectarianism. Critiquing a
position is welcome; attacking someone's school of thought is not.

## Reporting

Report a problem privately to the repository owner. If a report concerns a
religious-data accuracy issue, say which item and which source you believe is
correct — the owner routes data questions to scholars, and that routing depends
on the specificity of the report.

## Scope

This applies in the repository, in issues, in reviews, and in any space where
someone is representing this project.
